2장의 half adder는 고전 입력만 받아서 고전 덧셈기와 다를 게 없었다. 이번 장에서 입력을
**중첩** 으로 바꾸면, 같은 회로가 네 개의 덧셈을 한 번에 처리한다. 그리고 그 결과를
**측정** 하는 순간 무슨 일이 벌어지는지 본다.

## 게이트 5: H 게이트 — 중첩을 만든다

**Hadamard 게이트(아다마르 게이트, H)** 는 큐비트를 0/1의 **반반 중첩** 으로 보낸다.

| 입력 | 출력 |
|------|------|
| `\|0⟩` | `\|+⟩ = (\|0⟩ + \|1⟩) / √2` |
| `\|1⟩` | `\|−⟩ = (\|0⟩ − \|1⟩) / √2` |

`|0⟩`에 H를 걸면 `|+⟩` 상태가 된다. 측정하면 0과 1이 각각 50%로 나오는 상태다. `1/√2`
라는 숫자가 왜 붙는지는 곧 설명한다.

<Callout kind="note">
`√2`로 나누는 이유: 측정 확률은 각 항 계수의 **제곱** 이다. `|0⟩`과 `|1⟩`이 각각 50%가
되려면 계수가 `1/√2` 여야 한다. `(1/√2)² = 1/2 = 50%`. 두 확률의 합은 `1/2 + 1/2 = 1`.
</Callout>

## 입력을 중첩으로: 한 번에 네 개의 덧셈

half adder의 입력 `A`(q[0])와 `B`(q[1])에 X 대신 **H** 를 건다. 단계별로 상태를 따라가자.

**시작:** `|ψ₀⟩ = |0000⟩`

**H 두 개를 건 뒤** — `A`와 `B`가 각각 `|+⟩` 가 되어, 둘의 모든 조합이 동시에 존재한다.

<Eq label="ψ₁ — A, B 가 네 조합을 동시에 가짐">
|ψ₁⟩ = ½ (|0000⟩ + |0001⟩ + |0010⟩ + |0011⟩)
</Eq>

`q₁q₀` 부분이 `00, 01, 10, 11` — 즉 `(A,B)`의 네 가지 입력이 **한 상태 안에** 다 들어
있다.

**half adder(CX·CX·CCX)를 통과시킨 뒤** — 회로는 네 항 **각각에** 덧셈을 적용한다.

<Eq label="ψ₂ — 네 덧셈 결과가 동시에 들어 있음">
|ψ₂⟩ = ½ (|0000⟩ + |0101⟩ + |0110⟩ + |1011⟩)
</Eq>

각 항을 `|q₃q₂q₁q₀⟩ = |CARRY, SUM, B, A⟩` 로 읽어 보자.

- `|0000⟩` : 0+0 → sum 0, carry 0 ✓
- `|0101⟩` : 1+0 → sum 1, carry 0 ✓
- `|0110⟩` : 0+1 → sum 1, carry 0 ✓
- `|1011⟩` : 1+1 → sum 0, carry 1 ✓

**게이트를 한 세트만 걸었는데 네 개의 덧셈이 전부 끝나 있다.**

## 왜 이게 가능한가: 양자 연산은 선형이다

비결은 양자 연산(게이트)이 **선형(linear)** 이라는 데 있다. 선형이라는 건 이런 성질이다.

<Eq label="선형성">
f(α·x + β·y) = α·f(x) + β·f(y)
</Eq>

> 입력이 여러 상태의 **합(중첩)** 이면, 출력도 "각 상태에 따로 연산한 결과들의 합" 이다.

half adder 회로를 `f`라고 하면, 입력 `|ψ₁⟩`은 네 상태의 합이다. 선형성 덕분에 `f`는
네 항 각각에 덧셈을 적용하고 그 결과를 다시 합쳐 준다. 이것이 양자컴퓨팅에서 말하는
**양자 병렬성** 의 출발점이다.

<Callout kind="warn">
모든 함수가 선형인 것은 아니다. 예를 들어 `f(x) = x²` 는 `f(1+2) = 9 ≠ f(1) + f(2) = 5`.
양자 게이트는 **반드시** 선형이어야 한다 — 이 제약이 2부 9장에서 "양자 연산 = 행렬"로
이어진다.
</Callout>

## 슈뢰딩거의 고양이

`|ψ₂⟩` 처럼 여러 결과를 동시에 품은 상태를, 유명한 비유로 **슈뢰딩거의 고양이** 라
부른다.

> 상자 안에 고양이와, 확률적으로 작동하는 독약 장치가 있다. 상자를 **열어 보기 전** 까지
> 고양이는 "살아 있음"과 "죽어 있음"의 **중첩 상태** 다.

우리 회로에서 `|ψ₂⟩`는 네 개의 덧셈 결과가 겹쳐 있는, 정확히 그 "상자를 열기 전"
상태다.

## 측정 — 상자를 여는 순간

그럼 답을 어떻게 꺼내는가? **측정(measurement)** 한다. Composer에서는 측정 기호를 큐비트
줄에 올리고, 그 결과를 **고전 레지스터(classical register)** 의 비트로 받는다.

> 측정하면 중첩이 **무너진다(collapse)**. 여러 항 중 **딱 하나** 가 무작위로 골라지고,
> 큐비트는 그 하나의 상태로 확정된다. 고양이는 살아 있거나 죽어 있거나 — 둘 중 하나로
> 정해진다.

`|ψ₂⟩`를 측정하면 결과 `|ψ₃⟩`는 다음 넷 중 하나다.

<Eq label="ψ₃ — 측정 후, 넷 중 하나로 확정">
|ψ₃⟩ = |0000⟩  또는  |0101⟩  또는  |0110⟩  또는  |1011⟩
</Eq>

### 확률진폭과 측정 확률

각 항 앞에 붙은 계수(`|ψ₂⟩`에서는 모두 `½`)를 **확률진폭(probability amplitude)** 이라
한다. 어떤 항이 측정될 **확률은 그 진폭의 절댓값의 제곱** 이다.

<Eq label="측정 확률 = |진폭|²">
|½|² + |½|² + |½|² + |½|² = ¼ + ¼ + ¼ + ¼ = 1
</Eq>

네 결과가 각각 25% 확률로 나오고, 모든 확률을 더하면 1이 된다. (진폭의 제곱이 확률이라는
점은 4장의 복소수, 6장의 "확률진폭"에서 더 정확하게 다룬다.)

<Callout kind="warn">
**측정의 한계**: 회로는 네 덧셈을 동시에 했지만, 측정은 그중 **하나** 만 돌려준다. 그래서
양자 알고리즘 설계의 핵심은 "원하는 답의 진폭만 크게 만들어서, 측정했을 때 그게 잘 나오게"
하는 것이다. 그냥 병렬로 계산한다고 공짜로 답이 다 나오는 게 아니다.
</Callout>

### 측정은 어떤 "기저"로 하는가

위에서 한 측정은 `|0⟩`/`|1⟩` 중 하나로 결과가 나오는 측정 — 이를 **계산 기저
(computational basis, Z 기저)** 측정이라 한다. 측정에는 다른 기준(기저)도 있다는 점만 지금
기억해 두자. "기저"가 정확히 무엇인지는 2부 7장의 주제다.

## 진짜 양자 컴퓨터에서 돌리면

Composer의 시뮬레이터는 이상적인 결과를 준다. 하지만 실제 IBM 양자 장치(`ibm_brisbane`
같은)에서 같은 회로를 1024번 돌리면, 히스토그램에 `0000·0101·0110·1011` 뿐 아니라
**엉뚱한 값들도 섞여** 나온다.

> 실제 큐비트는 잡음에 약하다. 게이트 오류, 큐비트가 상태를 잃는 현상(decoherence) 때문에
> 계산이 틀어진다. 그래서 **양자 오류 정정(QEC, Quantum Error Correction)** 이 필수
> 연구 주제다.

설치 없이 쓰려면 구글 **Colab** 이 편하다.

```python
# Colab의 새 노트북 첫 셀에서 qiskit 설치

```

```python
from qiskit import QuantumRegister, ClassicalRegister, QuantumCircuit
from numpy import pi

qreg_q = QuantumRegister(4, 'q')
creg_c = ClassicalRegister(4, 'c')
circuit = QuantumCircuit(qreg_q, creg_c)

# A=1, B=1 입력 준비
circuit.x(qreg_q[0])
circuit.x(qreg_q[1])
circuit.barrier(qreg_q[0], qreg_q[1], qreg_q[2], qreg_q[3])

# half adder
circuit.cx(qreg_q[0], qreg_q[2])   # SUM ^= A
circuit.cx(qreg_q[1], qreg_q[2])   # SUM ^= B
circuit.ccx(qreg_q[0], qreg_q[1], qreg_q[3])  # CARRY = A·B

# 측정
circuit.measure(qreg_q[0], creg_c[0])
circuit.measure(qreg_q[1], creg_c[1])
circuit.measure(qreg_q[2], creg_c[2])
circuit.measure(qreg_q[3], creg_c[3])
```

```python
# 회로 그림 그리기
circuit.draw(output='mpl')
```

<Callout kind="summary">
- **H 게이트**: `|0⟩` → 0/1 반반 중첩(`|+⟩`)
- 입력을 중첩으로 넣으면 한 회로가 **모든 입력의 계산을 동시에** 수행 — 양자 연산이
  **선형** 이기 때문
- **측정**: 중첩이 무너져 결과 하나로 확정. 확률 = `|확률진폭|²`

- 1부 끝. 회로·게이트·중첩·측정을 봤으니, 2부에서 이 모든 것을 **벡터와 행렬** 로 다시
  정의한다.
</Callout>
